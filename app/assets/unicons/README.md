# Iconscout Unicons

Line icons downloaded from the official Iconscout Unicons repository:
https://github.com/Iconscout/unicons/tree/master/svg/line

Product page: https://iconscout.com/unicons

Copyright Design Barn Inc. Distributed under the accompanying IconScout Simple
License. The dashboard recolours these icons at render time and embeds them
locally, without a CDN dependency.

Additional assets: `lightbulb-alt`, `headphones-alt`, `credit-card`, `search`,
`exchange`, `database`, and `file-check-alt`. These identify page topics,
retention opportunities, event types, and empty states. All SVGs come from
`https://raw.githubusercontent.com/Iconscout/unicons/master/svg/line/{name}.svg`.
They are cached in memory and have empty alt text beside visible labels to avoid
repeating descriptions to screen readers. No animation or external requests run
during dashboard refreshes.
